# compla6

Team workspace utilities, version 0.6.4.

Requires Python 3.11 or newer. Native workflows target Linux x86-64.

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install .
```

Optional tool integration:

```sh
python -m pip install '.[mcp]'
```

See [installation](docs/INSTALL.md), [usage](docs/CONTROLLER_USAGE.md), and the
[API](docs/API.md). Results are in [R/README.md](R/README.md).
