## Implemented

- Native byte-exact archives for opaque bytes, Hadoop/OpenStack logs and static
  RLB1 relational bundles; arbitrary declared native candidate source.
- A bounded persistent relational-store protocol with independent state/query/
  export oracles, atomic acknowledgement checks, replay and continuation after
  reopen, merge, external kill and injected I/O failures.
- Immutable candidate/build inventories, exact build reuse, durable jobs,
  cancellation, result provenance, idempotent completion, separate budget tracks,
  compact comparison/resume, and best-eligible preservation.
- Source/binary/dependency/runtime and store accounting, deployment horizons and
  workload-specific gates. Mutable throughput has no static encoding-speed floor.
- Separate owner freeze/public recheck/private evaluation/aggregate disclosure
  for both workload families. An interrupted attempt consumes its existing latch;
  it cannot silently open private data again.
- Official MCP SDK 1.29.1 over stdio or authenticated loopback HTTP, an offline
  29-wheel CPython 3.12 dependency lock, host connection helpers and shared skill.
- A pinned Ubuntu OCI recipe and scoped AppArmor/seccomp policies that were
  actually built and exercised locally.

## Real Hadoop pilot

Public input: 469 objects, 24 groups, 33,977,121 canonical bytes. A predeclared group
split gives 351 training and 118 development objects. Ranking projects development
archive bytes to a 100,000,000-byte deployment horizon and adds fixed deployment
costs. This is a public development score. Nine native controls passed quality in
0.1.1; five met the encoding floor. Fresh final 0.2.1 rechecks:

| Candidate | All-object archive bytes | Actual deployment bytes | Development deployment projection | Encode MB/s | Decode MB/s | Eligible |
|---|---:|---:|---:|---:|---:|---|
| Train-only dictionary Zstd-1 | 1,238,721 | 2,098,920 | 7,791,389 | 151.92 | 153.57 | Yes |
| Luna template codec | 1,489,161 | 2,350,531 | 9,393,343 | 72.14 | 120.33 | No |

Both passed full correctness checks. Luna's result is larger and misses the
encoding-only 100 MB/s floor. The baseline remains best eligible. `pilot-summary.csv`
and `pilot-summary.json` trace all controls, failed/quick attempts and final checks
to complete raw records. The live model run took 3,004 seconds and reported
4,144,107 processed tokens, mostly cached input, with a host cost estimate of
$0.7701; this is not a subscription invoice.

## Limits

This is a working local research harness, not a production database or exhaustive
security/durability certificate. Mutable support covers a bounded four-table movie
schema, insert-only transactions, point reads, specified joins and exact export.
Full IMDb import, arbitrary SQL, updates/deletes, concurrent writers, storage
reordering and power-loss certification are outside the contract. Tiny-fixture
latency/write amplification must not be extrapolated to IMDb.

These public model trials establish neither general model superiority
nor quantified token savings. Cached builds are operational reuse, not cached
speed qualification. Deterministic/random tracks enforce recorded evaluation/wall
limits; the live pilot did not run an equal-budget random/human codec-design contest.

Codex 0.153.4 recognized a real generated project configuration and disconnect
restored it. ZCode 3.11.2-6792's guide and fixtures were checked. Neither had a
separate candidate-building model session. Windows/macOS execution, other
architectures, fully instrumented external libraries, hard instantaneous RSS/disk
limits and side-channel resistance are not certified.
