# Whole-dataset research

New research uses `evaluation_mode: whole_dataset` and defaults to compression software written from scratch. The public manifest contains only `split: corpus`; all supplied bytes are available for designing and fitting the encoder and independent decoder. Deliver a reproducible build, documented interface and measured speed/compression modes. Full scoring uses that exact corpus, with no held-out generalization claim. Existing cards without an evaluation-mode field keep their historical split interpretation.

The card requires `timing_policy.scope: whole-dataset-v1` and `accounting_policy: supervisor-decoder-v1`. New cards declare `timing_policy.operation: offline-plus-online-v1` and `encoding_floor_scope: combined`. Every dataset-dependent operation, including fitting, preprocessing and required generated-code compilation, counts toward end-to-end encoding. Each of seven combined trials sums its offline and online measurements before aggregation; data-independent builds are disclosed separately. At least one fast mode must reach 100 MB/s end to end, then continue seeking substantially better speed and compression. A slower maximum-compression mode remains useful alongside the fast mode; disclose size, all encoding stages, decoding and memory for each.

Dataset-derived artifacts declare `training.kind: whole-dataset` with the actual SHA-256 hashes of the corpus objects used. The decoder receives only its archive and declared runtime. Exact reconstruction, arbitrary-byte fixtures, independent objects, deterministic rebuilds, corruption rejection and diagnostics remain required.

The primary size policy is explicit. New research defaults to `standard-codec-available-v1`, excluding only separately pinned standard codec library files actually present in the decoder closure. All custom binaries, framing and required artifacts remain charged. `reported_accounting.corpus.actual.deployment_total_bytes` is then the primary score; `decoder_accounting.corpus.actual.deployment_total_bytes` retains strict V+B+A+D. Existing cards retain their original score. Static code is charged unless an independent component accounting method is explicitly commissioned.

`baseline_visibility` is independent of dataset mode. Visible runs receive completed same-card comparisons. Hidden runs expose the researcher's own evidence without supplied comparison tools. `implementation_policy` independently selects open or from-scratch research. The host prepares these choices before launch; prompts and `brief` derive their rules from that same card.

The original 0.5.3 Yelp experiment used the prepared 100,000,488-byte prefix, not the publisher's entire release. Its bytes, prompt, strict accounting and recorded results remain historical evidence.
