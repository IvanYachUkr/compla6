# Compression Lab 0.6.0 validation

The release replaces the active research contract with compression software written from scratch, a required fast mode and maximum-compression alternatives. New cards apply the 100 MB/s bare minimum to combined end-to-end encoding, including every dataset-dependent preparation step. Generated instructions, qualification, feedback and comparison metrics use the same scope. Existing cards and releases retain their original interpretation.

The trusted Prime RPC driver enforces version-2 completion limits: time, money, additional failure rounds, or a combination. A failed final answer cannot close the run while allowances remain. The metered gateway owns six capacity retries after 15, 30, 60, 120, 180 and 300 seconds, separately reserves each attempt and retains unknown charges. Tests cover early failed finish, final-round success, same-session crash recovery, ambiguous delivery, budget exhaustion, disabled SDK retries, failed-stream isolation and matching guardian behavior.

Fresh evidence: 141 focused regression tests, 14 real native SDK fixture tests and 17 release-tool tests passed. Of 50 native regression cases, 49 passed on the current source immediately. One MCP comparison launched a subprocess from the predecessor virtual environment and returned predecessor fields; that case passed with the matching 0.6.0 environment. The original failure and corrected check remain recorded. No model calls were made.

Two installed-package full evaluations on 966,144 synthetic bytes passed the mandatory correctness, independent reconstruction, corruption, diagnostics, reproducibility and resource gates. One regenerates fitted artifacts and measures offline, online and paired combined trials; the other has no preparation and equal online/combined trials. Both exports are retained. These are smoke integration checks and do not certify the 100 MB/s research floor. The installed root driver also exercised the real evaluator UID 995, completed exactly three additional rounds with native receipt acknowledgments and left all workspace files owned by the evaluator.

The installed capsule and default commands use 0.6.0. The paused gateway and guardian use the matching new tools; their restart left API admission disabled and the prior budget ledger unchanged. Historical candidate results, unresolved billing evidence and prior installed releases were preserved. New contracts require new research workspaces; this release does not resume the earlier commission or validate its codecs.

Machine-readable results and exact receipt hashes are in [current-release.json](../results/current-release.json); the wheel inventory check is [final-wheel.json](../results/final-wheel.json). The release manifest verifies packaged file bytes and modes. The installed manifest records the independently checked capsule and preserved predecessor.
