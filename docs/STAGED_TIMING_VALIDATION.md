# Staged timing validation, 0.5.6

The [validation receipt](../results/staged-validation.json) records the tested source, final wheel and installed-runtime results. This release changes research instructions and the encoding measurement contract; it makes no claim of better research outcomes.

The [full regression suite](../results/staged-suite/work/full-suite.json) passed all 346 tests with no skips. Its source, tests and schema stayed unchanged throughout the run. Final review then added two counterexamples: measured compilation selected a CPU outside the requested profile, and the standalone JSON schema accepted online-floor metadata that the Python validator rejected on legacy cards. Both failed before their fixes; [42 affected checks](../results/profile-schema-recheck/work/tests.json), including full native regeneration and diagnostics, then passed with no skips. The original wheel and before/after receipts are retained. The post-suite production changes are limited to compiler affinity and that schema condition.

The checks cover default continuation after qualification or improvement, explicit hidden-by-default owner opt-in, deep implementation guidance, legacy/new timing resolution, the online-only floor despite slow combined time, paired-trial arithmetic, exact reproduction for both dictionary samplers, modified-artifact rejection, charged deterministic rebuilds and missing-stage rejection. Seventeen release-tool checks also passed. Expected development failures and the corrected error-shape/predecessor fixtures remain recorded.

The [installed native verification](../results/installed-native/work/benchmark/SUMMARY.json) ran two complete evaluations on 966,144 synthetic bytes: one fitted dictionary candidate and one data-independent candidate. Both passed every required correctness, independent-decoding, corruption, diagnostic, rebuild and resource gate. Fitting was reproduced in diagnostics and all seven timed trials; online and combined trials were preserved. The data-independent candidate reported zero offline time and identical online/combined trials. Feedback and the export preserve the measured stage data and hypothesis evidence. These small smoke cases do not qualify the 100 MB/s research objective.

The final wheel's 105 package files match source bytes. The clean source and installed Python environments pass dependency checks. Native validation held the existing host benchmark lock in a private mount/PID namespace, and each process tree was drained before release. There were no model calls or frozen scientific benchmark reruns. Prior installed 0.5.3, 0.5.4 and 0.5.5 core files were verified unchanged.

Combined time is the sum of each trial's measured offline and online invocations, including required dataset-dependent compilation, before aggregation. Evaluator staging, hash verification and correctness/diagnostic work consume evaluation wall time but are excluded from codec timing; data-independent builds are disclosed separately. Source review must still establish that every dataset-dependent operation is declared. Existing sanitizer, build-sandbox and resource-measurement limits remain explicit in raw evidence.

The pending Yelp input retains its exact 100,000,488 bytes, models, resource profiles, total budgets, hidden comparisons and open implementation. Its new card selects offline/online/combined timing with the 100 MB/s floor on online encoding only. It is prepared, not launched. Existing Text8 and completed GLM work retain their original runtimes and contracts.
